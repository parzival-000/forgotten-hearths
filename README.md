# Forgotten Hearths

Forgotten Hearths is an archived and abandoned Minecraft NeoForge mod prototype, originally created for the CurseForge ModJam 2026: Echoes of the Past.

The concept was to discover abandoned homesteads, rekindle their forgotten hearths, and restore them into useful refuges.

Development stopped early. This repository is preserved as an archive of the original unfinished work. It should not be considered a finished, playable, or actively maintained mod.
