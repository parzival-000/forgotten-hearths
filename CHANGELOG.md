# Changelog

## 0.1.0 - Initial ModJam build

- Added woodland cottage, plains farmstead, and taiga shelter homesteads.
- Added the persistent four-stage Forgotten Hearth restoration loop.
- Added blackened and mended kettles, cracked and mended crocks, patchwork cloth, and a recipe fragment.
- Added three visible restoration furnishings and safe exact-marker replacement.
- Added Hearth Porridge, Root Stew, and Honeyed Oatcake.
- Added the Comforted refuge effect and server configuration.
- Added four advancements, structure loot, crafting recipes, tags, localization, original textures, and models.
- Added automated GameTests for marker safety, the full restoration loop, one-time reward gating, and structure-template loading.
- Added dedicated validation probes for save-stop-restart persistence and complete natural worldgen placement.
- Improved Hearth Porridge and Root Stew icons, relic/cloth icons, and the kettle, crock, and quilt furnishing models after an observed in-game texture pass.
- Added direct repair/restoration guidance to relic tooltips and clearer hearth/remnant instructions.
- Hid restoration-output furnishings from the creative tab to remove confusing duplicate entries while retaining their registry IDs for existing worlds.
- Added the missing Mended Crock block-item translation fallback.
